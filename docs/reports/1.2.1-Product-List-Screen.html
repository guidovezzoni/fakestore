Overview

User story 1.2.1 — Product List Screen was opened for development. This is the first user-facing screen, replacing the placeholder "Hello Android" composable.

Branch

Key Refinements

  • Scrollable product list with cards showing product image, title, and formatted price
  • Architecture: MVI pattern with ProductListUiState, ProductListUiIntent, ProductListUiEffect, and ProductListViewModel
  • Image loading: Asynchronous with placeholder and fallback handling
  • Deferred features:
    • Favourite toggle icon deferred to story 2.1.1
    • Loading, error, and empty states deferred to story 1.2.2
    • Bottom navigation deferred to story 1.2.3
  • Testing requirements: ViewModel unit tests and Compose UI tests required
  • Code coverage: 95%+ minimum

Compliance & Security

  • GDPR: No significant concerns — product catalogue data only
  • Security: Enforce HTTPS-only for external image URLs

Task Structure

  • 2 prerequisite sections (5 tasks): version catalog/Gradle, MVI scaffolding
  • 4 BDD sections (19 tasks): formatter, ViewModel, card composable, screen composable
  • 2 integration sections (3 tasks): strings/localisation, MainActivity wiring
  • 1 verification section (7 tasks): detekt, tests, kover, on-device checks

Key Design Decisions

  1. Coil 3 with OkHttp network engine (not Ktor) — reuses existing OkHttp stack
  2. Material icon placeholder/error for images — no custom drawable assets
  3. Formatting utility in ui/util/ — independently testable, per guidelines
  4. ProductListItem display model in ui/state/ — pre-formatted values, composables are purely presentational
  5. Stateful/stateless composable split — enables isolated Compose UI testing

Risks Flagged

  • Coil 3 runtime: Requires separate coil-network-okhttp artifact for network images (compiles without it but fails at runtime)
  • Currency locale: NumberFormat.getCurrencyInstance() defaults to locale's own currency — must explicitly override to USD
  • Deferred error handling: Result.failure silently swallowed in this story (empty product list) — by design, deferred to 1.2.2
