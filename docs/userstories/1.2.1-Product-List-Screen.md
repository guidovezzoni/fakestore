# Product List Screen

**Epic**: 1 — Product Catalogue
**Feature**: 1.2 — Product List Screen
**Modules created**: `:ui`; screen lives in `:app`

## User Story

As a user, I want a scrollable list of products (name, image, price) so that I can browse the catalogue.

## Acceptance Criteria

- [ ] Products are displayed in a lazy vertical list
- [ ] Each card shows: product image, title, price, and a favourite toggle icon
- [ ] Images are loaded asynchronously (e.g. Coil)
- [ ] The list is scrollable without UI jank on the full 20-item catalogue
- [ ] The screen is reachable via the bottom navigation bar

## Technical Notes

- Shared Compose theme and reusable card components live in `:ui`
- ViewModel lives in `:app`, consumes `GetProductsUseCase` from `:domain`
