# Favourites Screen Analytics

**Epic**: 2 — Favourites Management
**Feature**: 2.2 — Favourites Screen
**Modules**: `:app`, `:core`

## User Story

As a product owner, I want a `favourites_screen_viewed` analytics event logged when the Favourites screen loads.

## Acceptance Criteria

- [ ] `favourites_screen_viewed` is logged once each time the Favourites screen enters composition
- [ ] The event includes a `favourite_count` param reflecting the number of items shown at load time

## Technical Notes

- Same pattern as `product_list_viewed`: `LaunchedEffect(Unit)` triggers a ViewModel intent
