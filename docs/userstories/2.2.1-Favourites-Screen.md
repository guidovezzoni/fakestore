# Favourites Screen

**Epic**: 2 — Favourites Management
**Feature**: 2.2 — Favourites Screen
**Modules**: `:app`

## User Story

As a user, I want a Favourites screen showing only my saved products so that I can review them quickly.

## Acceptance Criteria

- [ ] The Favourites screen displays only products whose IDs are in the Room database
- [ ] Cards use the same layout as the Products screen (name, image, price, toggle icon)
- [ ] Removing a favourite from this screen removes it immediately from the list
- [ ] The screen is reachable via the bottom navigation bar

## Technical Notes

- The screen combines the full product list (from network/cache) with the favourite IDs (from Room) to build its list — no separate API call
- ViewModel consumes `GetFavouritesUseCase` and `GetProductsUseCase` from `:domain`
