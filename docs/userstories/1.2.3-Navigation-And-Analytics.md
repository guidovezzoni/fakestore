# Navigation & Product List Analytics

**Epic**: 1 — Product Catalogue
**Feature**: 1.2 — Product List Screen
**Modules**: `:app`, `:core`

## User Story

As a user, I want a bottom navigation bar giving access to Products, Favourites, and Profile so that I can switch screens at any time.

As a product owner, I want a `product_list_viewed` analytics event logged when the screen loads so that catalogue engagement is measurable.

## Acceptance Criteria

### Bottom Navigation
- [ ] Bottom bar is always visible with three labelled tabs: Products, Favourites, Profile
- [ ] The active tab is visually highlighted
- [ ] Switching tabs preserves the scroll position of the previously visited screen
- [ ] Navigation is implemented with Compose Navigation in `:app`

### Product List Analytics
- [ ] `product_list_viewed` is logged once each time the Products screen enters composition (not on every recomposition)
- [ ] The event is logged only on successful content display, not during loading or error states

## Technical Notes

- Routes defined as a sealed class / type-safe object in `:app`
- Feature screens do not depend on each other — navigation is orchestrated only in `:app`
- Use `LaunchedEffect(Unit)` in the composable to fire the event once per screen visit
- The ViewModel dispatches a `TrackScreenView` intent; the analytics call happens inside the ViewModel to keep composables free of side-effect logic
