# Hilt Dependency Injection

**Epic**: 1 — Product Catalogue
**Feature**: 1.1 — Data Layer & Analytics Setup
**Modules**: `:app`, `:core`, `:data`

## User Story

As a developer, I want Hilt configured end-to-end so that ViewModels, repositories, and the analytics client are injected automatically.

## Acceptance Criteria

- [ ] `@HiltAndroidApp` applied to the `Application` class in `:app`
- [ ] `@HiltViewModel` used on all ViewModels
- [ ] `:core` provides a Hilt module binding the Retrofit instance and `AnalyticsClient`
- [ ] `:data` provides a Hilt module binding repository implementations to their `:domain` interfaces
- [ ] No manual `object` or `companion object` factories remain for injectable types
