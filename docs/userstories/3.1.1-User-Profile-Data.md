# User Profile Data

**Epic**: 3 — User Profile
**Feature**: 3.1 — Profile Screen
**Modules**: `:domain`, `:data`

## User Story

As a user, I want to see my name and email fetched from the API so that I know which account is loaded.

## Acceptance Criteria

- [ ] `GET https://fakestoreapi.com/users/8` is called and the response maps to a `UserProfile` domain model (name, email, username)
- [ ] Name and email are displayed on the Profile screen
- [ ] `GetUserProfileUseCase` in `:domain` exposes `Flow<Result<UserProfile>>`

## Technical Notes

- `UserRepository` interface in `:domain`; implementation in `:data`
- Reuses the same Retrofit instance from `:core`
