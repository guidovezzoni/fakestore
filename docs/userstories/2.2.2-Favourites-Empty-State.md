# Favourites Empty State

**Epic**: 2 — Favourites Management
**Feature**: 2.2 — Favourites Screen
**Modules**: `:app`, `:ui`

## User Story

As a user, I want an empty-state message when no favourites exist so that the screen is never confusingly blank.

## Acceptance Criteria

- [ ] When the favourites list is empty, a descriptive message (e.g. "No favourites yet. Tap the heart on a product to save it.") is shown centred on screen
- [ ] The empty state is shown both on first launch and after the user removes all favourites
- [ ] The empty-state composable is reusable and lives in `:ui`
