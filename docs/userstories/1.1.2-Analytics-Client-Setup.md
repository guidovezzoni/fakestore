# Analytics Client Setup

**Epic**: 1 — Product Catalogue
**Feature**: 1.1 — Data Layer & Analytics Setup
**Modules**: `:core`

## User Story

As a developer, I want an analytics client set up in `:core` so that any module can log events without knowing the underlying SDK.

## Acceptance Criteria

- [ ] An `AnalyticsClient` interface is defined in `:core` with a single `fun logEvent(name: String, params: Map<String, Any> = emptyMap())` method
- [ ] A concrete implementation (e.g. logging to Logcat in debug, no-op in release, or a real SDK) is provided and wired via Hilt
- [ ] No feature module imports the analytics SDK directly — all calls go through the interface

## Technical Notes

- Keeping analytics behind an interface makes it trivial to swap the underlying SDK (Firebase, Mixpanel, etc.) without touching feature code
