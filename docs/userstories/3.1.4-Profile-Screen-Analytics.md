# Profile Screen Analytics

**Epic**: 3 — User Profile
**Feature**: 3.1 — Profile Screen
**Modules**: `:app`, `:core`

## User Story

As a product owner, I want a `profile_screen_viewed` analytics event logged when the Profile screen loads.

## Acceptance Criteria

- [ ] `profile_screen_viewed` is logged once each time the Profile screen enters composition
- [ ] The event is logged regardless of whether the profile data has loaded yet

## Technical Notes

- Same pattern as `product_list_viewed`: `LaunchedEffect(Unit)` triggers a ViewModel intent
