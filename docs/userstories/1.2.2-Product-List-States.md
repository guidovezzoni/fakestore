# Product List States

**Epic**: 1 — Product Catalogue
**Feature**: 1.2 — Product List Screen
**Modules**: `:app`

## User Story

As a user, I want loading, error (with retry), and empty states so that I always know what the app is doing.

## Acceptance Criteria

- [ ] A full-screen loading indicator is shown while the network call is in flight
- [ ] A full-screen error message with a "Retry" button is shown when the call fails
- [ ] Tapping "Retry" re-triggers the use-case
- [ ] An empty-state message is shown if the API returns an empty list
- [ ] The MVI state sealed class has exactly three variants: `Loading`, `Content`, `Error`

## Technical Notes

- State is managed in the ViewModel as `StateFlow<ProductListUiState>`
- MVI intent: `RetryClicked` triggers a new fetch
