# Bottom Navigation

**Epic**: 1 — Product Catalogue
**Feature**: 1.2 — Product List Screen
**Modules**: `:app`

## User Story

As a user, I want a bottom navigation bar giving access to Products, Favourites, and Profile so that I can switch screens at any time.

## Acceptance Criteria

- [ ] Bottom bar is always visible with three labelled tabs: Products, Favourites, Profile
- [ ] The active tab is visually highlighted
- [ ] Switching tabs preserves the scroll position of the previously visited screen
- [ ] Navigation is implemented with Compose Navigation in `:app`

## Technical Notes

- Routes defined as a sealed class / type-safe object in `:app`
- Feature screens do not depend on each other — navigation is orchestrated only in `:app`
